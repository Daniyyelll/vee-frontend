# Collection directory

Mode: Persuade through browsing. Audience: Vee customers exploring the live
catalog. Primary action: choose a category and open a product. The user chose
category browsing for the first screen and rejected excessive promotional copy.
The category directory composition was selected on the surface decision page.
Code-led build in the established botanical atelier world.
FORM: The `concept-seed --scope surface --mode persuade` roll used seed
`852b1cb2`. The user selected `directory` from the three structures in
`.impeccable/collection-options.json` and chose the code build path.

## Direction contract

THESIS: A quiet, persistent directory lets a shopper find the right category
while the products, not invented copy, carry the page.

OWN-WORLD: Warm paper, ivory, cocoa, blush and fine mineral seams; Bodoni Moda
headings, Manrope controls, square geometry and supplied product photographs.
No green in authored UI or concept imagery.

STORY: A visitor sees all live categories and their product counts, chooses one,
opens a product in the established detail flow, and adds an available item to
the existing bag.

FIRST VIEWPORT: The Vee navigation leads into a quiet, large collection title.
A narrow category index occupies the left side; a spacious product gallery sits
beside it. The selected category and result count are clear before products.
On mobile the category index becomes a touch-friendly horizontal directory above
the gallery. No promotional paragraph competes with the catalog.

SIGNATURE INTERACTION: The active category moves through a fine cocoa rule and
arrow while the gallery updates immediately. Back/Forward restores category
selection from the URL. Motion is restrained and disabled for reduced motion.

FINISH: Verify desktop and mobile composition, empty/loading/error states,
keyboard focus, URL navigation, and product actions before review.
